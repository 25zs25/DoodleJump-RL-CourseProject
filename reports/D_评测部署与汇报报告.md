## 模块目标与结论

本模块负责冻结实验协议、统计保留测试、核验浏览器推理、组织演示和课程材料。完整验收包含 5400 局：新学习策略 3900、随机和规则参考 600、旧模型在当前窗口复测 900。新权重导出后与 PyTorch 在 4320 组输入上动作完全一致。主要结论需以保留测试平均成绩表达，演示高分局不能作为整体效果证明。

本报告描述对应模块的技术成果、实现依据与验证方法。模块编号表示分工范围；实际参与的实现、复核、实验和写作工作由成员在末页据实填写。项目结果来自已保存的配置、权重与逐局记录。

## 5400 局的组成

39 组新学习策略包括主算法 27 组、速度消融 9 组，以及 PPO 采样诊断 3 组，每组 100 局，共 3900。随机与物理规则参考各在三个窗口评测，共 6×100=600。九个旧完整模型在当前窗口同一测试种子复测，共 900。总量不能把概率采样诊断或旧模型复测漏算。

## 统计口径与原窗口结果

先计算每训练种子的 100 局均值，再报告三个均值的平均及样本 SD。独立训练重复数量为 3；SD 描述种子间变异，不是所有地图回合的置信区间。随机和手写规则没有训练种子，表中不编造同口径 SD。

| 策略 | 原版得分均值 ± 种子 SD | 平均最高攀升 px | 得分≥3000 | 时限截断 |
| --- | --- | --- | --- | --- |
| 随机动作 | 262.5 | 14.3 | 0.0% | 0.0% |
| 物理规则参考 | 29765.8 | 6093.9 | 93.0% | 40.0% |
| DQN | 18476.5 ± 1145.6 | 3737.7 | 83.7% | 19.7% |
| Double DQN | 18584.2 ± 1969.7 | 3744.3 | 85.7% | 19.7% |
| PPO | 3944.8 ± 535.6 | 688.5 | 47.7% | 15.0% |


原 score 在滚屏时累计处理平台次数，与最高像素攀升不同。得分≥3000 是阈值事件比例，不是通关率。1500 次决策为时限截断，达到它也不表示永久安全。规则参考明确未训练，并用局部观测和原物理参数预测落点，不给神经网络提供教师标签。

## 结果边界和旧模型复测

DQN 与 Double DQN 均值只差 107.7 分，约 0.58%，不支持显著优劣结论。PPO 此配置表现更弱，但其算法和优化预算不同，不能推出所有策略梯度方法都不适合小游戏。跨窗口分数因原缩放和阈值变化不属于统一难度单位。

旧模型在同一当前窗口测试均分为 DQN 2511.2±543.8、Double DQN 2988.0±1280.5、PPO 2433.7±498.1；新模型分别为 18476.5、18584.2、3944.8。旧训练来自 405×720，网络规模相同，整次重训的差异不属于单一因素消融。

当前数据读取 results/native_v2/test_episodes.csv 和 baseline_episodes.csv；根目录 results/test_episodes.csv 属历史实验。逐局数据应与汇总 JSON 一起保留，使组员能重算结果，而不是只能观看图片。

## 浏览器部署与推理验收

浏览器 iframe 覆盖实际游戏视口，加载 upstream 原 p5 引擎、图片和音效。DQN/Double DQN 导出各层权重和偏置，JavaScript 按相同线性层、ReLU 顺序推理；PPO 部署骨干和策略头。外围页面提供模型选择、地图种子及原版得分和高度，地图种子用于复现，不是模型训练种子的下拉选项。

| 验证项 | 实测结果 |
| --- | --- |
| 新模型对照 | 12 模型×360 输入=4320 组 |
| 最大输出绝对误差 | 1.1492×10^-5 |
| argmax 动作不一致 | 0 |
| 当前原版浏览器对照 | 4202 物理帧一致 |
| 桌面与手机横向溢出 | 均未发现 |
| 手动控制、暂停与重开 | 已执行验证 |

float32 PyTorch 与 JavaScript 浮点运算出现小幅输出误差是允许的，动作一致和误差上限需同时保存。运行网页仅依赖本地 HTTP 服务，浏览器推理不需要 PyTorch 或联网；训练依赖与试玩依赖分别说明。

## 演示和失败的选择规则

默认 native_v2_dqn_full_h128_seed59_1000000 按验证成绩选择。种子 10019 是该模型验证集最高案例，得分 41949、最高攀升 8619.2 px；种子 10000 得分 1565、攀升 127.2 px，死亡原因 blackhole。两者均由真实网络驱动原引擎，不编写行动路线。

1500 决策的高分演示和 73 决策的失败演示，浏览器与 Python 对应计分和高度完全一致。它们分别展示可达到的行为与失败边界，不能替代 300 局均分。截图和 GIF 需标注模型、窗口、种子及是否来自验证集。

## 课程材料与复现交付

课程要求每队 3-4 人、准备约 13 分钟汇报，并让每位成员说明自己在组内工作。交付包括原版游戏和训练接口、三算法权重、消融与逐局评测、PPT、讲稿、小组技术报告和四个模块个人报告。个人报告的技术主体完整，但姓名、学号和实际贡献必须由成员确认；不能把分工计划当作已完成劳动记录。

当前汇报材料按 18 页组织，14 页主讲合计 780 秒，4 页附录供答辩。A 讲 1-4 页，B 讲 5-8 页，C 讲 9-11 页，D 讲 12-14 页，每人约 195 秒。正文说明任务、算法差异、观测动作奖励、验证选择和保留测试、失败案例与限制；页码和讲稿需保持一致。

复现时先确认窗口和文件版本，运行试玩检查原版外观，再按 README 的训练评测命令执行。报告数字来自实验记录；演讲流畅或页面美观不能替代技术验收。未来更新 PPT 后应另记录结构、可编辑图表与逐页视觉检查，不能继续沿用旧文件哈希作为新版本凭证。
